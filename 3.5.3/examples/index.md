# Examples

The following examples demonstrate the core workflows of the Cuvis SDK. The pages below show the **Python** implementation, generated from the runnable Jupyter notebooks. C and C++ implementations of the same examples live in the SDK's `examples/` directory (`cuvis.c.examples` and `cuvis.cpp.examples`).

Prerequisites

All examples require:

- A Cuvis SDK installation
- Camera settings files (provided with your camera and the SDK)
- For examples 2–5: a recorded measurement file (`.cu3s`) or the [demo dataset](https://cloud.cubert-gmbh.de/s/SDKSampleData)

| Example                                                                                                                     | Description                                          |
| --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| [1 – Take Snapshot](https://cubert-hyperspectral.github.io/cuvis.sdk/3.5.3/examples/example_1_take_snapshot/index.md)       | Connect to a camera and capture a single measurement |
| [2 – Load Measurement](https://cubert-hyperspectral.github.io/cuvis.sdk/3.5.3/examples/example_2_load_measurement/index.md) | Load a recorded `.cu3s` file and inspect its data    |
| [3 – Reprocess](https://cubert-hyperspectral.github.io/cuvis.sdk/3.5.3/examples/example_3_reprocess/index.md)               | Re-apply spectral processing to a stored measurement |
| [4 – Exporters](https://cubert-hyperspectral.github.io/cuvis.sdk/3.5.3/examples/example_4_exporters/index.md)               | Export measurements to common file formats           |
| [5 – Record Video](https://cubert-hyperspectral.github.io/cuvis.sdk/3.5.3/examples/example_5_record_video/index.md)         | Continuously record a video stream of measurements   |
